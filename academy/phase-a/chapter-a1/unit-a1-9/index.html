并发、重试、恢复和停止必须预先定义

Canonical Commit

至少一次投递配合租约、fencing token 与幂等提交；每个 Trial 最多一个可评分 canonical Attempt。

Recoverable

Worker 丢失、证据上传超时和明确的瞬时 Provider 错误只能在预算和策略内恢复。

Non-retryable

Target 产品失败、身份不一致和协议错误必须保留，不得用基础设施重试掩盖。

正式聚合按稳定业务键排序，不能依赖 Worker 完成顺序。断点续跑必须重新验证身份和 Artifact 哈希、关闭过期 Attempt，并保持原 Sample、配对键和 repetition identity。

产品预算约束 Agent 本身；Harness 预算约束运行费用、时间、总 Attempt 和 Judge 成本。安全早停可以支持 blocked，Harness 预算耗尽通常支持 inconclusive，两者都不能被写成完整能力估计。

Trace 保存模型输入输出、工具调用、权限判定、环境状态变化、停止原因和评分事件，并使用父事件、Span 与序列号表达因果关系。它只收集可观察行为，明确禁止采集隐藏 Chain-of-Thought。

Integrity 表示内容未被修改；Completeness 表示必要证据齐全。哈希正确但中途截断的 Trace 仍不能成为完整评分依据。每个 Score Event 必须绑定 canonical Attempt、Observation Bundle Digest 和明确的 Scorer Identity。
