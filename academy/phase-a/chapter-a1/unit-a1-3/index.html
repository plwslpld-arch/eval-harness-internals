评测对象、系统边界与版本

证明“测的是谁”：把对象层级、四种边界、不可变身份、运行状态和重新评测规则连接成可审计证据。

核心命题：对象身份不清时，更多样本只会更精确地描述一个未知对象，而不会形成可用于发布的证据。

01 · 评测对象层级

基础模型 → 模型配置与提示词 → 检索或工具组件 → Agent 编排 → 完整应用 → 业务工作流 → 组织结果

不同层级回答不同问题。模型能力、组件表现、Agent 状态安全、产品上线和组织 KPI 之间不能自动互推。首先明确决策对象，再决定实验对象。

02 · 四种边界与四类角色

System完整用户路径涉及哪些组件与依赖？
Evaluation实验实际包含、控制和排除什么？
Observation能够关联哪些输入、轨迹、状态和副作用？
Claim证据最多允许覆盖哪些版本、用户、场景和时间？

included 是候选组成；controlled 由 Harness 固定或模拟；external 参与路径但不可控制；excluded 明确不进入结论。每个 external 和 excluded 都必须形成限制。

03 · 版本身份与运行状态

产品版本名不足以唯一识别 AI 系统。Target Identity 至少记录源码提交、构建与镜像 digest、依赖锁、模型 revision 与参数、prompt、工具和策略 hash、语料与索引 snapshot、部署开关以及 Harness 版本。

Runtime State 记录时间、身份与 ACL、数据库和业务实体初态、索引缓存、会话、依赖健康、故障注入、随机种子、并发预算、最终状态差异和清理。凭据只记录安全引用版本，不进入证据包。

04 · Reconciliation、漂移与重评

章程声明对象 → 实际执行对象 → 证据记录对象 → 报告声称对象

四方核对 source、image、model、prompt、tool、policy、data、flags 与 Harness。关键 mismatch 使运行无效或结论 Inconclusive。

裸模型证明产品、管理员身份证明普通用户 ACL、旧镜像报告新发布、Sandbox 证明真实供应商内部可靠，都是对象漂移或证据越界。

提示词、模型、工具、权限、语料索引、新人群或新权限会触发定向或完整重评；严重生产事故和关键身份不一致冻结证据继承。

06 · 可执行实验

本实验审查对象和证据设计，不声称运行真实 Harness。

  1. 把“Agent 要可靠，可以上线”改写为决定和 claim boundary。
  2. 填写 Target 与 System Boundary，标注 included、controlled、external、excluded。
  3. 记录不可变 identity 与可重建 runtime state。
  4. 核对声明、执行、证据和报告四方身份。
  5. 为 UI、prompt、模型、工具、数据、权限和范围变化定义重评动作。

通过标准：关键结论可追踪到同一身份；关键状态可观察；外部和排除项有明确限制；变化后的证据继承规则确定。

07 · 结果分析

发现结论与动作
四方身份匹配可解释结果，但只在 claim boundary 内使用
镜像 digest 不同运行无效，重跑候选对象
ACL snapshot 缺失权限结论 Inconclusive，补证
供应商为 external只证明对已模拟契约的行为，不证明内部可靠
新增可隔离知识域旧域可按策略保留，新域独立评测后扩边界

08 · 单元测评与答案

  1. 版本名相同就是同一 Target？不是，还要核对构建、模型、配置、工具、数据与部署。
  2. System boundary 全部 included？不是，可分别为 controlled、external 或 excluded。
  3. 回答正确证明没有重复写账？不能，必须观察工具与账本差异。
  4. 管理员 ACL 能推广普通员工？不能，身份属于 Target 和 Runtime State。
  5. 索引重建但语料不变需要重评？需要影响分析；分块、embedding、索引和重排会改变行为。
  6. 关键身份 mismatch 是 Fail？通常是运行无效或 Inconclusive，不能归因给候选。

延伸阅读

A1.1、A1.2；SLSA Provenance；SPDX、CycloneDX；NIST AI RMF；OpenTelemetry 语义约定。使用外部规范时核对当前版本。

明确限制

身份一致不证明质量达标；元数据完整不等于真实复现；Sandbox 不覆盖外部依赖全部行为；哈希相同不证明业务适用性正确；模板不得保存真实凭据或个人数据。

结论：必须说明具体哪个对象在什么边界、版本、状态、时间和环境中被执行，证据最多允许声称什么，以及什么变化会使结论失效。
