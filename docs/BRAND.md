# Eval Harness 源码内核品牌

## 视觉概念

完整标志由三组彼此衔接的对象组成，每组都对应 Eval Harness 证据链里的一个阶段。左侧的三个彩色圆点代表预声明实验样本，因为评测要从事先确定的计划出发，所以它们也是整组图形的起点。中间的菱形代表内容寻址证据，括号形态的「门」代表 Gate，两者连在一起表达证据先接受资格检查，再进入质量判断。门后的绿色菱形代表通过资格验证后形成的质量决定，而它与门前菱形的距离，也把输入证据和最终决定清楚地区分开。整组图形不使用机器人头像，也不拼接任何上游项目商标，以免读者把这套教材误认成某个 Agent 产品或上游项目的官方材料。

标志周围始终保留至少一个样本圆点直径的完整留白——如果空间不足，应缩小整组图形，而不能压缩某一侧的安全距离。使用标志时要保持原始方向和宽高比例，因为旋转或单向拉伸会破坏样本、证据与 Gate 之间的阅读顺序。不要改成机器人形象，也不要在主标志中加入上游 Logo，这两项限制共同守住项目身份边界。项目名称在正文中首次出现时写作「Eval Harness 源码内核」，后文可以根据语境简称，而代码里的技术标识、包名和仓库名继续保留原有英文形式。
